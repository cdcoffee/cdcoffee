# 肽与提取物研究

> 把结构预测、路线比对与质量口径串成一条可复现的研究链。

## 何时用

- 要对某类活性肽或天然提取物做结构研究、路线比对。
- 不同来源、不同提取路线的资料需要统一整理口径。
- 要把研究结论整理成原料档案或产品化输入。

## 输入

- 目标分子或提取对象的描述与序列 / 来源信息。
- 已有研究资料与检测记录（用于回查）。
- 本地可执行的结构预测与可视化能力。

## 输出

- 结构预测结果与可视化图（含可信度说明）。
- 路线比对表：维度一致、结论可追溯。
- 原料 / 产物档案模板：字段统一、留复核位。

## 做法

1. **明确问题**：先写清「要判断什么」，再选方法，不先跑工具。
2. **本地推理**：序列类分析优先在本机完成，数据不出本机。
3. **同维度比对**：路线比较用同一组字段，缺项标缺失而非猜测。
4. **标可信度**：预测结果与实测结论分开写，不互相替代。
5. **归档**：把方法、参数范围、验收条件写进技能，供下次复现。

## 验收

- [ ] 每条结论都能指回输入与所用方法。
- [ ] 预测值与实测值明确区分。
- [ ] 档案模板字段齐全，含复核人与复核状态。
- [ ] 输出不含配方、工艺参数、检测数值与产能信息。

## 不做什么

- 不把计算结果当成实验结论。
- 不在对外材料里写知识产权数量或宣传性技术表述。
- 不把未实施的路线写成已落地产线。
- 不外传序列数据与原始检测记录。

# 视频与内容生产线

> 从创意简报到分镜、成片与质检，把内容做成可复跑的流水线。

## 何时用

- 要批量产出短视频、宣传片或分镜内容。
- 同一系列内容跨多期，风格与角色需要保持一致。
- 成片质量不稳定，需要可勾选的质检清单。

## 输入

- 制作信息收集表：主题、受众、时长、调性、禁用表述。
- 资产清单：角色、场景、音乐、音效的可复用描述。
- 台词与分镜要点（含需要复述确认的长指令）。

## 输出

- 创意简报与需求表。
- 主时间线与分镜脚本表、分镜图。
- 成片 + 质检记录 + 可复用资产更新。

## 做法

1. **复述闸门**：长指令先复述一遍确认，确认前只做只读动作。
2. **先资产后分镜**：角色与场景定稿再写镜头，避免每期重画。
3. **图声一体**：台词、音效写进同一份分镜规格，减少后期对不齐。
4. **批量生成、逐个质检**：按质检清单逐条勾，不过就回炉。
5. **沉淀**：把稳定的提示词结构、参数范围、避雷项写回技能。

## 验收

- [ ] 同一角色跨镜头外观一致。
- [ ] 台词、字幕、音效三者对齐，无错字与禁用表述。
- [ ] 质检清单全勾，失败项有回炉记录。
- [ ] 成片不含经营数据、客户名称、未公开案例与内部路径。

## 不做什么

- 不用宣传性数字做字幕；数字必须过口径闸门。
- 不把未实施项目剪成已落地案例。
- 不在生成物里放置真实人物肖像或第三方素材而不核实授权。
- 不跳过复述确认就批量开跑。

# 简洁技能卡 · 索引

> 一张卡讲清一个能力。按「可公开」标准撰写，不含经营数据、客户信息、工艺参数、内部路径与凭据。

## 为什么单独做一层简洁卡

完整技能副本包含实现脚本、参数与内部流程，适合复用但不适合阅读与交接。简洁卡只保留**可迁移的方法骨架**：换个行业、换家公司，把场景词替换掉就能用。

| | 简洁卡（本目录） | 完整技能副本 |
|---|---|---|
| 篇幅 | 一页 | 多文件 + 脚本 |
| 内容 | 定位 / 输入 / 输出 / 步骤 / 验收 / 边界 | 实现细节、参数、模板、自检 |
| 读者 | 人、新同事、新岗位 | 执行环境、复用者 |
| 外发 | 可按可公开标准分享 | 仅内部 |

## 统一模板

每张卡固定六段，缺一段不算合格：

```
# 技能名
> 一句话定位
## 何时用       触发场景，写得能判断「这次该不该用」
## 输入         开工前必须拿到的东西
## 输出         交付物长什么样
## 做法         三到五步，每步能验收
## 验收         可勾选的完成条件
## 不做什么     安全边界与常见误用
```

## 新增一张卡

1. 复制模板，按六段填满，控制在**一页以内**。
2. 只写方法与判断标准，不写具体数字、名称、路径、参数。
3. 跑 `python tools/check_public_safe.py`，通过后才提交。
4. 在本索引追加一行，并同步到仓库主页的技能导览表。
